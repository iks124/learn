# Work2: CBOW 词向量训练（带负采样）

## 训练方式

**答案：直接运行一条命令即可，无需分次训练。**

## 快速开始

```bash
cd code
python cbow_ns.py
```

## 训练过程

运行 `cbow_ns.py` 后，程序会：

1. 读取 `../data/zh.txt` 中的分词语料
2. 构建词汇表（过滤低频词）
3. 生成 CBOW 训练样本
4. 训练 **10 个 epoch**
5. 保存词向量到 `zh_vectors.txt`

## 超参数配置

- 词向量维度: **200**
- 上下文窗口: **4**
- 负采样数量: **5**
- 批量大小: **512**
- 学习率: **0.025**
- 训练轮数: **10**

## 输出结果

- **zh_vectors.txt**: 训练得到的词向量文件
- 格式：第一行为词汇表大小和维度，之后每行为一个词及其向量
